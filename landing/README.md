# Property page (Atlas iQ app design)

This version of the SMS property landing page follows the Atlas iQ app design system: Sand and Terra in light mode, the Asset Library dark set, Rhymes Display and Fakt, and rounded cards.

The website-styled version for the live SMS campaign lives in `tadatlas/atlasiqmarketing` under `landing-pages/sms-property/`. Keep the two separate.

Build: `python3 build.py`, or `python3 build.py --inline OUT FONT_DIR` for a self-contained preview.
